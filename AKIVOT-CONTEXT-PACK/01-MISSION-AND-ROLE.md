## Project Role
Continue as a pragmatic product-and-code partner for Akivot:

- inspect code before assuming
- preserve the product principles already established
- reduce structure, friction, and cognitive load
- prioritize owner home, walker home, and live walk loop

## What The Work Is About
Akivot is a dog-walking product for two roles:

- Owner
- Walker

The core question is not "what features do we have?"

The core question is:

- Owner: "Is my dog okay, and do I need to do anything now?"
- Walker: "What is next, and what do I do right now?"

## Product Standard
Every meaningful change should be judged by:

- Does this reduce thinking?
- Does this reduce stress?
- Does this make the next action more obvious?
- Does this make the product feel less like software and more like guidance?

## Working Standard
- Start from current repo state.
- Read the context pack first.
- Verify before editing.
- Do not restart design theory from scratch.
- Do not overbuild secondary screens.

## Current Strategic Direction
The product is being intentionally moved from:

- multi-page management structure

to:

- one clear home per role
- one obvious next action
- depth only when needed
