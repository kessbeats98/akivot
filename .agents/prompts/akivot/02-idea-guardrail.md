# Prompt: Check A Product Idea Before Planning

```text
Use akivot-product-enforcer.

Check the following idea before planning or coding:

[PASTE IDEA HERE]

Answer using the exact Product Guardrail Check structure:
- Goal
- Layer: Core / Depth / Support / Later
- User emotion affected
- Immediate uncertainty reduced
- Next action clarified
- Visible UI complexity impact
- Explicitly not building
- Smallest implementation path
- Decision: Proceed / Reduce scope / Demote / Reject
- Reason

If it adds capability but not immediate clarity, reject it or demote it to
Depth/Later.
```
