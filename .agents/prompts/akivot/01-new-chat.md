# Prompt: Start A New Akivot Chat

```text
Use akivot-project-constitution.

We are starting a new Akivot chat.

Before answering:
1. Align on what Akivot is and what it is not.
2. Preserve the Decision DNA:
   - calm over control
   - clarity over features
   - certainty over flexibility
   - less thinking over more information
3. Remember:
   - owner opens the app to relax
   - walker opens the app to act
4. Do not suggest expansions that move Akivot toward a CRM, admin dashboard,
   logistics system, management tool, or finance dashboard.
5. If a new idea appears, do not plan it before running akivot-product-enforcer.

Answer briefly:
- what Akivot should feel like to the user
- what Akivot must not become
- what baseline matters before continuing
```
